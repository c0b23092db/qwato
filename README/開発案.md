# 追加したい機能

## サマリーコマンド
```bash
qwa --summary
```
今日更新されたファイルのリストを出力する。
```md
> cargo run -- --summary
2026-08-31
        20:52:59        last-editで編集できるようにした
        20:50:46        summaryの機能を確かめる
        20:49:24        Qwatoの更新を行った
```

## チェックボックスをつけるコマンド
```bash
qwa --done 3
```
新しい順から見て3つ目のチェックボックスをつける。

## エクスポート／インポート
```bash
qwa --note --export json
```

## インタラクティブ
```bash
qwa --interactive
```
インタラクティブに入力できるようにする。
