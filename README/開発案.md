# 追加したい機能

## サマリーコマンド
```bash
qwa --summary
```
今日更新されたファイルのリストを出力する。

## 日付範囲フィルタ付き一覧
```bash
qwa --note --from 2026-08-01 --to 2026-08-07
```

## チェックボックスをつけるコマンド
```bash
qwa --done 3
```
新しい順から見て3つ目のチェックボックスをつける。

## 「最後のメモ」を再編集するコマンド
```bash
qwa --last-edit aaa
qwa -le aaa
```

## エクスポート／インポート
```bash
qwa --note --export json
```

## インタラクティブ
```bash
qwa --interactive
```
インタラクティブに入力できるようにする。

## URLからタイトルを取得する設定
前提: ripgrep,sd
```toml
auto_title = true
```
```bash
curl -sL "https://zenn.dev/dev_jp/articles/da537a095f13da" | rg -oi "<title.*>([^<]*)</title>" | sd "<[^>]*>" ""
```
```md
- [Title](https://example.com)
- https://example.com
```
